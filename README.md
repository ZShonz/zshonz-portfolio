# ZShonz Portfolio Preview

Vite + React 单页作品集预览，精选作品区使用 React Bits InfiniteMenu。

## 本地预览

可以直接双击 `index.html`，或在项目目录运行：

```powershell
npm install
npm run dev
```

然后打开 `http://localhost:4173`。

## 当前范围

- Hero、InfiniteMenu 项目文件夹、个人介绍、能力方法、联系页尾
- PC、平板和移动端响应式布局
- 轻量滚动出现动画与减少动态效果支持
- 项目详情入口暂以同页目录作为占位
